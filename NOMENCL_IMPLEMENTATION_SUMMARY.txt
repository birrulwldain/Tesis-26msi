## 🔧 Build Process (What Happens Now)

When you run `./prepare-submission.sh`:

```
1. ✓ Clean old build files
2. ✓ XeLaTeX pass 1 (generates .nlo file)
3. ✓ BibTeX (bibliography)
4. ✓ makeindex (processes symbols from .nlo → .nls)  ← NEW!
5. ✓ XeLaTeX pass 2 (incorporates symbols)
6. ✓ XeLaTeX pass 3 (final formatting)
7. ✓ Verify PDF
8. ✓ Create submission package
```
